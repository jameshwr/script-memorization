📱 安装到手机主屏幕

把背诵 App 添加到桌面，像原生 App 一样使用

方式一：Netlify 一键部署 推荐 免费

最简单的方式，拖拽上传，30 秒得到一个网址。

1
准备部署文件

在电脑上把 memorization 文件夹里的所有文件打包成一个 ZIP 压缩包。

💡 直接压缩文件夹里的文件，不要嵌套一层文件夹
2
打开 Netlify Drop

在电脑浏览器打开 app.netlify.com/drop

不需要注册账号，直接用
3
拖拽上传

把 ZIP 文件拖到网页中间的上传区域，等待几秒钟。

4
获取网址

上传完成后，页面会显示一个网址，格式类似 xxx.netlify.app。把这个网址发到自己手机上（微信/QQ/邮件都行）。

5
手机用 Safari 打开

在 iPhone 上点击网址，选择用 Safari 浏览器打开。

⚠️ 必须用 Safari，微信/QQ 内置浏览器不行
6
添加到主屏幕

点击 Safari 底部中间的 分享按钮（方框+向上箭头）
往下滑，找到 "添加到主屏幕"
名称填"剧本背诵"，点右上角 添加

✓
完成！

回到桌面，你会看到"剧本背诵"的 App 图标。点开就是全屏运行，和原生 App 一模一样！

❓ 常见问题

安装后需要联网使用吗？
第一次打开需要联网加载。之后就可以离线使用了（Service Worker 会自动缓存）。音频文件需要网络加载（如果部署在网上）。
学习进度会丢吗？
进度存在手机浏览器里，只要不卸载 App、不清空浏览器数据就不会丢。建议定期用"导出数据"功能备份一下。
换手机了怎么办？
旧手机上点设置 → 导出数据 → 保存 JSON 文件 → 新手机上导入这个 JSON 文件，进度就同步了。
可以增加新的句子吗？
可以。把新剧本发给我，我帮你生成新句子和音频，更新后重新部署就行。你已有的学习进度不会受影响。
Netlify 的网址可以改名字吗？
可以。注册一个免费 Netlify 账号后，就可以把网址改成自定义名字（比如 yourname.netlify.app）。不注册也能用，只是名字是随机的。
